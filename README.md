# เช็คชื่อคลาส Clude AI

เว็บเช็คชื่อผู้เข้าเรียนแบบออนไลน์ ธีมขาว-เขียว ใช้ได้บนคอมพิวเตอร์ แท็บเล็ต และมือถือ
ผู้เรียนกด **เช็คอิน** แล้วเซ็นชื่อบนหน้าจอ จากนั้นกด **เช็คเอาท์** ตอนออกจากคลาส
ข้อมูลทุกครั้งจะถูกบันทึกลง **Google Sheet** โดยอัตโนมัติ

## ความสามารถ

- รายชื่อผู้เรียนพร้อมบริษัทและตำแหน่ง ค้นหาและกรองสถานะได้ (ยังไม่มา / กำลังเรียน / ออกแล้ว)
- บันทึกเวลาเข้า เวลาออก รวมเวลาเรียน และลายเซ็น
- บันทึกลง Google Sheet ทันที และทุกเครื่องที่เปิดหน้าเว็บจะเห็นข้อมูลตรงกัน (อัปเดตทุก 15 วินาที)
- ถ้าอินเทอร์เน็ตหลุด ระบบจะเก็บข้อมูลไว้ในเครื่องก่อน แล้วส่งเข้าชีตให้เองเมื่อกลับมาออนไลน์
- นำเข้ารายชื่อจากไฟล์ CSV / Excel หรือพิมพ์รายชื่อลงในชีตโดยตรงก็ได้
- ส่งออกรายงานเป็น Excel / CSV หรือคัดลอกไปวางใน Google Sheets
- ดูข้อมูลย้อนหลังตามวันที่

## โครงสร้างไฟล์

```
clude-ai-attendance/
├── index.html            หน้าเว็บ (ไฟล์เดียว รวม HTML/CSS/JS)
├── config.js             ตั้งค่า URL ของ Google Apps Script
├── roster-template.csv   ตัวอย่างรูปแบบไฟล์รายชื่อ
├── apps-script/
│   ├── Code.gs           โค้ดฝั่ง Google Sheet (วางใน Apps Script)
│   └── appsscript.json   ค่าตั้งของ Apps Script (ใช้เมื่อ deploy ด้วย clasp)
└── README.md
```

## ขั้นตอนติดตั้ง

### 1) สร้าง Google Sheet และใส่โค้ด Apps Script

1. สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น `เช็คชื่อคลาส Clude AI`
2. ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทิ้ง แล้ววางโค้ดจาก `apps-script/Code.gs` ทั้งหมด → กด **บันทึก** 💾
4. ที่แถบด้านบน เลือกฟังก์ชัน **`setup`** แล้วกด **เรียกใช้ (Run)**
   - Google จะขอสิทธิ์ใช้งาน Sheet และ Drive → กด **อนุญาต**
     (ถ้าขึ้นว่า "Google ไม่ได้ยืนยันแอปนี้" ให้กด *ขั้นสูง* → *ไปที่โปรเจกต์ (ไม่ปลอดภัย)* ซึ่งเป็นปกติของสคริปต์ที่เราเขียนเอง)
   - กลับไปที่ชีต จะเห็นชีต **รายชื่อ** และ **บันทึกเวลา** ถูกสร้างขึ้น

### 2) เผยแพร่เป็นเว็บแอป (Deploy)

1. ใน Apps Script กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กดรูปเฟือง ⚙️ เลือกประเภท **เว็บแอป (Web app)**
3. ตั้งค่า
   - **เรียกใช้ในฐานะ (Execute as):** ฉัน (Me)
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** ทุกคน (Anyone)
4. กด **ทำให้ใช้งานได้** แล้วคัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)

> ทดสอบได้โดยเปิด `URL/exec?action=ping` ในเบราว์เซอร์ ถ้าเห็น `{"ok":true,...}` แปลว่าพร้อมแล้ว

### 3) ใส่ URL ใน `config.js`

```js
window.APP_CONFIG = {
  SCRIPT_URL: "https://script.google.com/macros/s/XXXXXXXX/exec",
  SHEET_URL:  "https://docs.google.com/spreadsheets/d/XXXXXXXX/edit",   // ไม่บังคับ
  POLL_SECONDS: 15
};
```

### 4) ใส่รายชื่อผู้เรียน (เลือกวิธีใดก็ได้)

- **ผ่านหน้าเว็บ:** กดปุ่ม **นำเข้ารายชื่อ** แล้วเลือกไฟล์ CSV / Excel (ระบบหาคอลัมน์ ชื่อ / นามสกุล / รหัส / บริษัท / ตำแหน่ง ให้เอง)
- **พิมพ์ลงชีตโดยตรง:** ใส่ข้อมูลในชีต **รายชื่อ** ตั้งแต่แถว 2 (คอลัมน์ id ปล่อยว่างได้ ระบบจะสร้างให้)

### 5) นำขึ้น GitHub และเปิดใช้ GitHub Pages

```bash
git init
git add .
git commit -m "เว็บเช็คชื่อคลาส Clude AI"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/clude-ai-attendance.git
git push -u origin main
```

จากนั้นที่หน้า repo บน GitHub: **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)`** → Save
รอสักครู่ จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/clude-ai-attendance/` เปิดได้ทุกอุปกรณ์

> จะอัปโหลดไฟล์ทั้งหมดขึ้นเว็บเซิร์ฟเวอร์อื่นก็ได้เช่นกัน ขอแค่ `index.html` กับ `config.js` อยู่ในโฟลเดอร์เดียวกัน

## ข้อมูลใน Google Sheet

**ชีต "บันทึกเวลา"** — หนึ่งแถวต่อหนึ่งคนต่อหนึ่งวัน

| วันที่ | ชื่อ-นามสกุล | รหัส | บริษัท/หน่วยงาน | ตำแหน่ง | เวลาเข้า | เวลาออก | รวมเวลา | สถานะ | ลายเซ็น |
|---|---|---|---|---|---|---|---|---|---|

- คอลัมน์ **ลายเซ็น** เป็นลิงก์ "ดูลายเซ็น" ไปยังไฟล์รูปใน Google Drive (โฟลเดอร์ `ลายเซ็น - เช็คชื่อคลาส Clude AI`)
- คอลัมน์ K–N เป็นข้อมูลของระบบและถูกซ่อนไว้ (คอลัมน์ O คือเวลาที่อัปเดตล่าสุด) **อย่าลบหรือย้ายคอลัมน์** เพราะหน้าเว็บอ่านข้อมูลตามตำแหน่งคอลัมน์
- ถ้าไม่ต้องการเก็บรูปลายเซ็นลง Drive ให้แก้ `SAVE_SIGNATURE_TO_DRIVE = false` ใน `Code.gs`

## แก้ไขโค้ด Apps Script ภายหลัง

หลังแก้โค้ด ต้องกด **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ✏️ แก้ไข → เวอร์ชัน: เวอร์ชันใหม่ → ทำให้ใช้งานได้**
วิธีนี้ URL `/exec` จะคงเดิม ไม่ต้องแก้ `config.js`

## ข้อควรรู้ด้านความปลอดภัยและความเป็นส่วนตัว

- **อย่า commit รายชื่อจริงลง repo สาธารณะ** — รายชื่อเก็บใน Google Sheet อยู่แล้ว (`.gitignore` กันไฟล์ `*roster*.csv` และ `*.xlsx` ไว้ให้)
- ใครที่ได้ URL ของเว็บแอปจะส่งข้อมูลเช็คชื่อเข้าชีตได้ และเห็นรายชื่อ/บริษัท/ตำแหน่งผ่านหน้าเว็บ ควรแชร์ลิงก์เฉพาะผู้เรียนในคลาส
- ถ้าต้องการให้ repo เป็นส่วนตัว ใช้ GitHub Pages กับ repo private ได้เฉพาะบางแพ็กเกจของ GitHub

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| ขึ้น "เชื่อมต่อ Google Sheet ไม่ได้" | ตรวจ `SCRIPT_URL` ว่าลงท้ายด้วย `/exec` และตั้งสิทธิ์เป็น "ทุกคน" / ลองเปิด `URL/exec?action=ping` |
| แก้โค้ดแล้วไม่มีผล | ต้อง deploy เป็น "เวอร์ชันใหม่" (ดูหัวข้อด้านบน) |
| ขึ้น "ออฟไลน์ · รอส่ง n รายการ" | ข้อมูลยังอยู่ในเครื่อง จะส่งเข้าชีตเองเมื่ออินเทอร์เน็ตกลับมา อย่าล้างข้อมูลเบราว์เซอร์ระหว่างนี้ |
| นำเข้าไฟล์ Excel ไม่ได้ | ต้องต่ออินเทอร์เน็ต (ใช้ไลบรารี SheetJS จาก CDN) หรือบันทึกไฟล์เป็น CSV แล้วนำเข้าแทน |
